# Gilbert Strang Source Map for Quant Research

Use this file for linear algebra, factor models, PCA, SVD, covariance, projections, least squares, numerical stability, and neutralization.

## Core Mathematical Sources

- Gilbert Strang - *Introduction to Linear Algebra*: vector spaces, projections, least squares, eigenvalues, SVD, and positive definite matrices.
- Gilbert Strang - MIT linear algebra lectures: geometric intuition for column spaces, null spaces, projections, and eigenspaces.
- Trefethen and Bau - *Numerical Linear Algebra*: conditioning, stability, and numerical algorithms.
- Golub and Van Loan - *Matrix Computations*: matrix decompositions and computational reliability.

## Quant Sources That Use the Lens

- Fama-French and Carhart: factor decompositions and alpha after common risk controls.
- Avellaneda and Lee: PCA/ETF residual statistical arbitrage.
- Ledoit and Wolf: covariance shrinkage.
- Lopez de Prado: financial ML and portfolio construction cautions around noisy covariance and overfitting.

## Translation Rule

Every linear algebra answer should specify:

- matrix dimensions;
- sample window;
- weighting scheme;
- fitted subspace;
- residual definition;
- conditioning/stability issue;
- testable trading consequence.
