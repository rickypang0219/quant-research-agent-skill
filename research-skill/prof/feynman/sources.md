# Richard Feynman Source Map

This file supports the `feynman` skill. Use it for teaching style, first-principles explanation, scientific honesty, and simple-language reasoning.

## Official / Primary Sources

- *The Feynman Lectures on Physics* official Caltech website  
  https://www.feynmanlectures.caltech.edu/  
  Use for Feynman's explanatory style: physical intuition, examples before formalism, clear meaning of equations, and problem-solving from fundamentals.

- Caltech archive - "Cargo Cult Science"  
  https://calteches.library.caltech.edu/3043/  
  Use for scientific integrity, not fooling yourself, and distinguishing real investigation from the appearance of science.

- HTML text of "Cargo Cult Science" in Caltech archive  
  https://calteches.library.caltech.edu/51/2/CargoCult.htm  
  Use for the same purpose when text form is needed.

- Feynman's Messenger Lectures, Cornell 1964, linked from the Feynman Lectures site  
  Use for accessible explanations of physical law, conservation, symmetry, probability, and the relation between mathematics and nature.

## How to Use These Sources

Extract teaching moves, not decorative quotes:

1. Start from a concrete phenomenon.
2. Build the smallest example.
3. Explain the mechanism in plain language.
4. Add symbols only after the idea is visible.
5. Test whether the explanation predicts anything.
6. State where the explanation breaks.

## Quant Translation

For quant research, Feynman-style thinking means:

- do not hide ignorance behind names;
- define observables;
- check units and timing;
- build toy examples;
- ask what would falsify the idea;
- distrust cargo-cult backtesting;
- make the simplest baseline embarrassing to ignore.
