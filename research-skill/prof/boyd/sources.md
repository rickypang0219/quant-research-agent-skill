# Stephen Boyd Source Map

Use these sources for convex optimization, numerical optimization, control, and disciplined modeling.

- Stephen Boyd and Lieven Vandenberghe - *Convex Optimization*  
  https://web.stanford.edu/~boyd/cvxbook/

- Stanford EE364a - Convex Optimization I  
  https://web.stanford.edu/class/ee364a/

- Stanford EE364a lecture slides  
  https://web.stanford.edu/class/ee364a/lectures.html

- Stanford EE364b - Convex Optimization II  
  https://stanford.edu/class/ee364b/

- Boyd et al. - Convex Optimization Short Course  
  https://web.stanford.edu/~boyd/papers/cvx_short_course.html

- CVXPY documentation and examples  
  https://www.cvxpy.org/

## Quant Translation

For each source-inspired idea, extract:

1. variables;
2. objective;
3. constraints;
4. convexity;
5. solver;
6. diagnostics;
7. sensitivity test.
