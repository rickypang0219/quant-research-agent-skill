# Paper Trading Review Checklist

- [ ] Paper period covers enough market states.
- [ ] Strategy config matches backtest config.
- [ ] Live data source matches expected schema.
- [ ] Feature drift measured.
- [ ] Signal drift measured.
- [ ] Orders generated as expected.
- [ ] Rejections explained.
- [ ] Latency measured.
- [ ] Slippage measured.
- [ ] Risk limits triggered correctly.
- [ ] Reconciliation completed daily.
- [ ] No unexplained position or balance mismatch.
- [ ] Kill switch tested.
