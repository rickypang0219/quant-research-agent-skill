# Model Validation Workflow

## Purpose

Independently challenge a model before it affects capital.

## Validation Areas

- model purpose;
- assumptions;
- data lineage;
- feature construction;
- leakage risks;
- estimation/calibration;
- validation split;
- robustness;
- benchmark comparison;
- implementation parity;
- risk impact;
- monitoring plan.

## Output Standard

1. Model summary
2. Intended use
3. Assumptions
4. Data review
5. Methodology review
6. Validation tests
7. Implementation review
8. Monitoring plan
9. Limitations
10. Approval verdict
