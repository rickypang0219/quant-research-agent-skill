# workflow/backtest Skill Pack

This folder contains a backtesting workflow skill for quant research and live-trading development.

## Files

```text
workflow/backtest/
  SKILL.md
  formulas.md
  experiments.md
  data_contracts.md
  checklists.md
  sources.md
```

## Intended Use

Use this skill pack when moving from a trading idea to:

1. vectorized alpha research,
2. parameter search,
3. train/forward validation,
4. event-driven replay,
5. paper trading,
6. small-capital live deployment.

## Core View

Vectorized backtesting is for speed.

Event-driven backtesting is for realism.

A strategy is not live-tradable until it survives both.
