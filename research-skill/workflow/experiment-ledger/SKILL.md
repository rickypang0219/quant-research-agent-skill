# Experiment Ledger Workflow

## Purpose

Prevent p-hacking and research amnesia. Every serious experiment should leave a trail.

## Core Rule

If you cannot reconstruct what was tried, the best result is not evidence.

## Required Record

- hypothesis;
- dataset version and fingerprint;
- code version;
- config;
- parameter search space;
- number of trials;
- metrics;
- validation split;
- rejected variants;
- final selected parameters;
- result;
- verdict;
- next action.

## Output Standard

Produce or request an experiment manifest before accepting performance claims.
