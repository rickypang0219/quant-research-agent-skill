# Anti-P-Hacking Checklist

- [ ] Number of tried ideas recorded.
- [ ] Parameter grid/search space recorded before selection.
- [ ] Failed variants recorded.
- [ ] Forward test not reused for tuning.
- [ ] Final test set touched once.
- [ ] Heatmaps inspected, not only best point.
- [ ] Multiple-testing risk discussed.
- [ ] Deflated Sharpe or similar adjustment considered.
- [ ] Narrative written before seeing final result where possible.
